What AXIS actually is (one paragraph):
AXIS is a modular signal-generation pipeline for NIFTY/BANKNIFTY index options that collects market data (Dhan), computes layered option/volume-profile-based directional scores, runs strategy checklists (e.g., GVOF), runs analyst/verifier LLM-based checks, applies risk and dedup gates, and (when approved) emits Telegram alerts and persists signal metadata/paper trades in Supabase-backed tables.
